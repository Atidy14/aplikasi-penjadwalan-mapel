# Aplikasi Penjadwalan Mapel Sekolah

## Deskripsi
Aplikasi web ini dibangun untuk mempermudah proses penjadwalan mata pelajaran di sekolah. Dibangun menggunakan teknologi modern dengan arsitektur **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, dan **Prisma ORM**.

## Arsitektur
- **Framework**: Next.js 14+ (App Router)
- **Bahasa**: TypeScript
- **Styling**: Tailwind CSS
- **Database ORM**: Prisma
- **Linting**: ESLint

## Persyaratan Sistem
- Node.js (direkomendasikan v18 ke atas)
- npm / yarn / pnpm

## Cara Menjalankan Secara Lokal

1. **Clone repository** (jika belum):
   \\\ash
   git clone <url-repo-anda>
   cd <nama-folder>
   \\\

2. **Instalasi dependensi**:
   \\\ash
   npm install
   \\\

3. **Konfigurasi Environment**:
   Salin file \.env.example\ ke \.env\ (jika ada) dan sesuaikan variabel konfigurasi (seperti \DATABASE_URL\).

4. **Menjalankan Server Pengembangan**:
   \\\ash
   npm run dev
   \\\

5. Buka [http://localhost:3000](http://localhost:3000) di browser Anda untuk melihat hasilnya.
